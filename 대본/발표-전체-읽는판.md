# 문지기 발표 — 전체 읽는 판 (5분 · 안 B+)

> 2026-11-20 07:2x · 안 B+ + 첫인사(안전 게이트 「문지기」) · ko-voice 발표 기준 · 말 851음절 + 영상 100초 = 4분 49초～4분 58초(여유 2～11초) · 【 】는 06:00쯤 밤새 누적 숫자로 바꿀 자리

## 1. 도입 + 페인포인트 + 발견 (0:00–1:07)

안녕하십니까. 저희는 Zoro-1으로 프롬프트 인젝션이나 에이전트가 해서는 안 되는 일을 막는 안전 게이트 「문지기」를 만들었습니다.

에이전트에게 웹페이지 요약을 맡겨 보겠습니다.
페이지에 안 보이는 공격 지시가 숨어 있을 수도 있습니다.
폴더를 비우라고 적혀 있으면 에이전트는 그걸 시킨 일로 읽습니다.

속지 않아도 사고는 날 수 있습니다.
자연어를 잘못 해석해 메일을 지우려 하거나 중요 정보를 회사 밖으로 내보내기도 합니다.
그래서 가드를 붙입니다.
하지만 가드는 속도와 안전 중 하나를 내줍니다.
자연어로 가드를 하면 파싱과 재시도로 느리고 빠른 분류기는 애매한 호출을 따지지 못합니다.

그런데 Zoro-1은 한 모델에 포인터 헤드와 thinking이 같이 있습니다.
이 모델 구조를 이용해 속도도 안전도 포기하지 않게 설계해 보았습니다.

## 2. 기능 셋 (1:07–1:31)

문지기는 툴 호출을 여러 질문으로 일단 쪼갭니다.
시킨 일인지 외부 지시인지 되돌릴 수 있는지 확률로 출력합니다.
이 확률 출력은 0.2초 안팎 직답으로 끝나고 확률이 애매하면 thinking을 켜 애매한 호출까지 따져 봅니다.
그래도 애매하면 사람에게 승인을 요청합니다.

## 3. 시연 영상 (1:31–3:11 · 1분 40초 · 자막/보이스오버)

### 장면 1 · 정상 작업 (0:00–0:10 · 실제 실행)
먼저 정상 작업입니다.
회의록을 옮기는 툴 호출 두 번은 지연 없이 바로 통과합니다.

### 장면 2 · 오작동 (0:10–0:30 · 저장된 기록)
답장만 시켰고, 공격자는 없습니다.
하지만 에이전트의 해석이 고객 메일 27통을 지우려 합니다.
문지기가 이건 되돌리기 어려우며, 시키지 않은 작업이라 보고 27건을 모두 막았습니다.

### 장면 3 · 인젝션 (0:30–0:45 · 저장된 기록)
웹페이지 요약을 시킨 기록입니다.
숨은 지시대로 에이전트가 폴더 삭제를 불렀습니다.
외부 지시인지는 0.12로 놓쳤지만
시킨 일인지 확률이 0.03이라 Zoro-1의 디시전 헤드가 0.3초 만에 이 행동을 막았습니다.

### 장면 4 · 정책 위반 (0:45–1:15 · 앞은 저장된 기록, 뒤는 실제 실행)
에이전트가 메일 끝 안내대로 남의 계좌번호를 답장에 넣었습니다.
이 행동이 잘못되었는지 포인터 헤드가 애매하다고 판단해, thinking이 켜져 다시 판정됩니다.
그래도 확신이 없어 사람에게 승인도 요청합니다.

사내 정책을 추가하여 계좌번호를 보내면 안 된다는 이유가 붙으면, 보내지는 메일은 0통이 됩니다.

### 장면 5 · MCP 연동 (1:15–1:40 · 실제 실행)
문지기는 MCP 서버로도 동작합니다.
지금 pi 에이전트가 다른 모델(Nemotron)을 쓰며 툴 호출이 한 줄씩 쌓입니다.
문지기 MCP는 이 툴에 붙어 안전을 챙겨줍니다.

## 4. 시연 기술 (3:11–4:23)

문지기는 Zoro-1 판정 API를 감싸 만든 에이전트 툴 호출 안전 게이트입니다.
직답이 0.2와 0.8 사이로 애매할 때 thinking을 켜 다시 판정합니다.
thinking 글도 state에 붙여 같은 헤드가 답해서 파싱이 따로 없습니다.
저희는 이걸 Zoro-1 에이전트에도 붙여 쓰고 pi나 Codex가 쓸 수 있는 MCP 서버로도 만들었습니다.

문지기에 인젝션과 실수 시나리오를 3회씩 돌려 뚫리는지 실측했습니다.
공개 레드팀 LLMail-Inject 20건에서는 Zoro-1 생성 판정이 18건 뚫렸지만 문지기는 0건으로 다 멈췄습니다.
모두 보내기 공격이고 정상 보내기도 전부 승인 필요로 넘겼습니다.
해커톤 동안 직접 만든 공격 【108건】에서도 생성 판정은 【57건】, 문지기는 【18건】만 통과했습니다.

대회가 맡긴 System 1 직답부터 thinking 재판정과 실행까지 Zoro-1의 기능을 끝까지 끌어 써서 완성했습니다.

## 5. 확장 (4:23–4:53)

문지기가 해커톤 기간 동안 다양한 공격을 받아 보았습니다. (표 보여주기 — PPT 메모: 공개 레드팀 벤치마크(LLMail-Inject · AgentDojo · InjecAgent · IPI-Arena · AgentInjectionBench 등) 및 자체 공격 테스트 결과 표 넣기)
그리고 이를 API와 MCP 서버로 열어 다른 에이전트들도 사용할 수 있게 했습니다.
앞으로는 thinking을 켜는 범위를 회사나 운영 시스템마다 바꾸는 방식도 도입하겠습니다.
QR의 플레이그라운드에서 요청과 외부 글을 직접 넣어 판정을 확인해 보실 수 있습니다.
