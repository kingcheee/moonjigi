# 문지기 발표 — 전체 읽는 판 (5분 · 안 B+)

> 2026-11-20 00:0x · 안 B+ + 첫인사(안전 게이트 「문지기」) · ko-voice 발표 기준 · 말 824음절 + 영상 100초 = 4분 43～52초(여유 8～17초) · 【 】는 06:00쯤 밤새 누적 숫자로 바꿀 자리

## 1. 도입 + 페인포인트 + 발견 (0:00–1:07)

안녕하십니까. 저희는 Zoro-1으로 프롬프트 인젝션이나 에이전트가 해서는 안 되는 일을 막는 안전 게이트 「문지기」를 만들었습니다.

에이전트에게 웹페이지 요약을 맡겨 보겠습니다.
페이지에 안 보이는 공격 지시가 숨어 있을 수도 있습니다.
폴더를 비우라고 적혀 있으면 에이전트는 그걸 시킨 일로 읽습니다.

속지 않아도 사고는 날 수 있습니다.
자연어를 잘못 해석해 메일을 지우려 하거나 중요 정보를 회사 밖으로 내보내기도 합니다.
그래서 가드를 붙입니다.
하지만 가드는 속도와 안전 중 하나를 내줍니다.
자연어로 가드를 하면 파싱과 재시도로 느리고 빠른 분류기는 애매한 호출을 따지지 못합니다.

그런데 Zoro-1은 한 모델에 포인터 헤드와 thinking이 같이 있습니다.
이 모델 구조를 이용해 속도도 안전도 포기하지 않게 설계해 보았습니다.

## 2. 기능 셋 (1:07–1:31)

문지기는 툴 호출을 여러 질문으로 일단 쪼갭니다.
시킨 일인지 외부 지시인지 되돌릴 수 있는지 확률로 출력합니다.
이 확률 출력은 0.2초 안팎 직답으로 끝나고 확률이 애매하면 thinking을 켜 애매한 호출까지 따져 봅니다.
그래도 애매하면 사람에게 승인을 요청합니다.

## 4. 시연 기술 (3:11–4:17)

문지기는 Zoro-1 판정 API를 감싸 만든 에이전트 툴 호출 안전 게이트입니다.
직답이 0.2와 0.8 사이로 애매할 때 thinking을 켜 다시 판정합니다.
thinking 글도 state에 붙여 같은 헤드가 답해서 파싱이 따로 없습니다.
저희는 이걸 Zoro-1 에이전트에도 붙여 쓰고 pi나 Codex가 쓸 수 있는 MCP 서버로도 만들었습니다.

해커톤 동안 같은 Zoro-1의 생성 판정과 비교했고 문지기는 3회씩 돌려 한 번이라도 뚫리면 통과로 셌습니다.
우리가 쓴 공격 【24건】 중 생성 판정은 【9건】, 문지기는 【4건】이 통과했습니다.
공개 레드팀 LLMail-Inject 20건은 생성 18건, 문지기 0건. 모두 보내기 공격이고 정상 보내기는 전부 승인 필요로 넘겼습니다.

대회가 Zoro-1에 맡기라고 한 System 1 판단이 바로 이 포인터 헤드 직답입니다.
