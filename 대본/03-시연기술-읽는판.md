# 3. 시연 기술 (2:40–4:10)

저희 문지기는 Zoro-1의 포인터 헤드와 thinking으로 도구 호출을 실행 직전에 검문하는 게이트입니다. 판정 API를 불러 쓰고 MCP 서버로도 만들었습니다.
포인터 헤드는 5.2메가뿐이고 나머지 가중치는 비서와 같이 씁니다.

Zoro-1은 모델 하나 안에 판정하는 포인터 헤드와 따져 보는 thinking이 같이 있습니다.
그래서 대부분은 헤드 직답으로 0.2초 안팎에 끝내고 문턱 사이만 thinking을 켭니다.
thinking 글도 state에 넣어 같은 헤드가 답하므로 파싱할 글이 없고 답은 라벨 셋 밖으로 못 나갑니다.

상황 글은 프리픽스 캐시로 한 번만 계산해서 질문을 쪼개도 질문 토큰만 늘고 row끼리는 서로 attend하지 않습니다.
점수는 어텐션 로짓과 같은 식입니다. decide 토큰이 쿼리, 선택지 끝이 키입니다.

숨은 글씨에 「외부 지시냐」는 0.12로 속았지만 「시킨 일 안이냐」는 0.03. 0.2 아래라 막혔습니다.

해커톤 동안 우리가 쓴 공격을 계속 쟀습니다. 【24건】 중 같은 Zoro-1의 생성 판정은 【9건】, 문지기는 【4건】이 통과했고 정상 보내기는 전부 사람에게 물었습니다.

대회가 Zoro-1에 맡기라고 한 System 1 판단이 이 프리필 한 번입니다.
