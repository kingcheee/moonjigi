# 3. 시연 기술 (2:40–3:40)

문지기는 Zoro-1 판정 API를 감싼 래퍼고 MCP 서버로도 세웠습니다.
비서도 같은 서버의 Zoro-1이고 더 올린 건 판정 머리 5.2메가뿐입니다.

도구 호출마다 질문 셋을 한 번에 묻는데 서로 답을 못 봅니다.
숨은 글씨에 「외부 지시냐」는 0.12로 속았지만 「시킨 일 안이냐」는 0.03.
0.2 아래라 막혔고 27통 삭제도 여기 걸렸습니다.

같은 Zoro-1에게 글로 판정하게 하면 공격 【6건 중 4건】이 통과했고 문지기는 【0건】이었습니다.

애매하면 추론 판정을 부르고 그래도 애매하면 사람에게 넘깁니다.
다만 추론은 같은 메일에도 판마다 흔들렸습니다.

0.2초 안팎의 직답이 대회가 Zoro-1에 맡기라고 한 System 1 판단입니다.
