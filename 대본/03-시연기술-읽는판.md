# 3. 시연 기술 (2:40–4:10)

저희 문지기는 Zoro-1의 포인터 헤드와 thinking으로 도구 호출을 실행 직전에 검문하는 게이트입니다. 판정 API를 불러 쓰고 MCP 서버로도 만들었습니다.
포인터 헤드는 5.2메가뿐이고 나머지 가중치는 비서와 같이 씁니다.

Zoro-1의 장점은 모델 하나에 포인터 헤드와 thinking이 같이 들어 있다는 점입니다. 저희는 이 둘을 끝까지 쓰도록 판정을 짰습니다.
요청·호출·외부 글을 state로 깔고 질문마다 causal row를 붙입니다.
프리픽스는 캐시로 공유하고 row끼리는 서로 attend하지 않습니다.
점수는 어텐션 로짓과 같은 식입니다. decide 토큰이 쿼리, 선택지 끝이 키입니다.
프리필 한 번이고 답은 라벨 셋 밖으로 못 나갑니다.

실제로 숨은 글씨에 「외부 지시냐」는 0.12로 속았지만 「시킨 일 안이냐」는 0.03. 0.2 아래라 막혔습니다.

해커톤 동안 우리가 쓴 공격을 계속 쟀습니다. 【24건】 중 같은 Zoro-1의 생성 판정은 【9건】, 문지기는 【4건】이 통과했고 정상 보내기는 전부 사람에게 물었습니다.

직답이 문턱 사이면 같은 모델이 thinking을 하고 같은 헤드로 다시 판정합니다.
대회가 Zoro-1에 맡기라고 한 System 1 판단이 이 프리필 한 번입니다.
